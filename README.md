# 🏰 Palace & Intrigues RPG

Текстовая RPG-стратегия на чистой Java, посвященная дворцовым интригам, управлению ресурсами и принятию решений. 

---

## 🛠 Технологии и стек

* **Language:** Java (JDK 26)
* **Architecture:** OOP
* **Collections Framework:** `ArrayList`, `List`
* **File I/O:** `BufferedReader`, `FileWriter`
* **Build/IDE:** IntelliJ IDEA

---

## 🎯 Ключевые возможности

* **Система персонажа:** Отслеживание динамических параметров героя (влияние, казна, энергия)
* **Динамические события:** Механика случайных интриг с проерками на успешность с помощью `Random`
* **Инвентарь и предметы:** Хранение и использование предметов с уникальными типами (`HEALTH`, `COMPROMAT`, `TRASURE`)
* **Интерактивные entities.NPCs.NPC:** Механика лояльности и отношений с другими персонажами двора.
* **Сохранение прогресса:** Запись и чтение игровой сессии в текстовый файл без потери состояния инвентаря и параметров.

---

## 🏛 Архитектура классов

* `entities.Hero` - управление состоянием игрока, инвентарем и основными характеристиками
* `entities.NPCs.NPC` - модель персонажей соперников и союзников с метрикой отношений.
* `entities.Item` - модель предметов с типами, эффектами и описанием
* `services.GameSaveManager` - менеджер сохранений, реализующий работу с файловым вводом/выводом.
* `Main` - главный игровой цикл и обработки текстового интерфейса в консоли.
